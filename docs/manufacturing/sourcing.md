## US distribution vs US manufacturing

Most electronics here are *distributed* from the US (DigiKey - Minnesota, Mouser - Texas,
McMaster-Carr, Adafruit, SparkFun, Pololu, PiShop.us) but manufactured elsewhere.
Parts believed to be designed and built or assembled in the US (verify): Atlas Scientific EZO
circuits and probes (New York), Apogee quantum sensor (Utah), Adafruit and SparkFun breakout
boards (assembled in New York / Colorado around non-US sensor ICs), OSH Park PCBs, 80/20
extrusion (Indiana) if chosen over Misumi, Bud enclosures (Ohio). Raspberry Pi boards are made in
Wales, UK. Mean Well supplies, LEDs, fans, motors, rails and the ESP32 are Asian-made.
A project with domestic-content requirements should treat only the items it has certificates
for as US-made.

## Commodity parts without traceable datasheets (risk)

Circulation pump, PTC heater, mist maker, flow meter, float switches. These are functionally
non-critical for data quality (their effects are measured by calibrated sensors) but they are a
reproducibility risk. `bom.csv` lists an industrial alternative for each. Record the exact
purchased item (photo, label, seller, date) in the build log.

## Supplier evaluation

| Supplier | Use for | Note |
|----------|---------|------|
| DigiKey / Mouser | ICs, connectors, Mean Well, TRACO, Bridgelux, ESP32 dev kits, Atlas, Adafruit boards | authorised distribution, datasheets, stable part numbers |
| McMaster-Carr | fasteners, sheet, tubing, fittings, gaskets | fast, generic brands, no country guarantee |
| Misumi USA | extrusion cut to length, brackets, linear rail (configurable) | per-millimetre cut service removes the need for a saw |
| Pololu | stepper drivers, motors, regulators | US-made boards, good documentation |
| Adafruit / SparkFun | sensor breakouts, Pi accessories | open hardware files for every board |
| Atlas Scientific | pH / EC | isolation and calibration documentation |
| Apogee | PAR reference | calibration certificate |
| Amazon / AliExpress | commodity pumps, heater, belts | no traceability; buy spares from the same lot |
| OSH Park (US) / JLCPCB | PCBs | upload `fab/gerber/`; specify 2 oz copper |
