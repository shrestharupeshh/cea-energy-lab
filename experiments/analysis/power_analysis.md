## Reading the table

- Study A: a single 4x4 Latin square (6 residual df, Dunnett-adjusted) is adequate only for large
  effects. Smaller effects need a second square (8 runs) or are reported as estimates with wide intervals.
- Study C: the 10 % energy-per-biomass target needs low unit-to-unit variability and more than four runs
  for conventional power; the run count for Study C is fixed only after U1-U2.
- Monte Carlo error on each entry is about +/- 0.02 to 0.04.
